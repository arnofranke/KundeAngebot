KUNDEN & ANGEBOTE – iPhone-Web-App
====================================

Die Anwendung speichert die Auftragsdaten lokal auf dem Gerät (localStorage) und kann offline genutzt werden, nachdem sie einmal geladen wurde.

FUNKTIONEN
- Dashboard: offene Aufträge / Angebote erstellt
- Kunde, Telefon, Adresse
- Termin
- Aufgabenbeschreibung
- HAB, Stammholz, Äste, VRA
- Sonstiges
- Fotos mit iPhone-Kamera oder Fotomediathek
- Standort übernehmen
- Apple Karten
- Angebot erstellt / offen
- Suche
- Bearbeiten / Löschen
- Daten exportieren und importieren

INSTALLATION AUF DEM IPHONE
1. Die Dateien müssen unter einer HTTPS-Webadresse erreichbar sein.
2. Die Adresse auf dem iPhone in Safari öffnen.
3. Teilen → "Zum Home-Bildschirm"
4. "Als Web-App öffnen" aktivieren (falls angezeigt).
5. "Hinzufügen" wählen.

WICHTIG
Die App benötigt für Installation als Web-App HTTPS. Die Daten bleiben lokal auf dem jeweiligen Gerät. Für einen späteren Mehrgerätebetrieb (iPhone + Mac + mehrere Mitarbeiter) wäre eine Server-Datenbank sinnvoll.
